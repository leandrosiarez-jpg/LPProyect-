# Contenedores de Red
---

El contenedor de red consiste en interconectarse con diferentes contenedores para realizar una comunicación con demas contenedores o para la repartición de recursos y datos con un Host.

Se debe de crear zonas aisladas para habilitar a numerosos contenedores que se comuniquen de una forma efectiva además segura. Esto mismo propone de varios estandares con la intención de regular la redes y su contenedores entre ellos hay 2 tipos de modelos llamados.

Red de contenedores (**CNM**) & el otro Interfaz de red de contenedores apodado (**CNI*)
