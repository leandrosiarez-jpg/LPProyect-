# ¿Como instalar GNS3?

## Requisitos para instalarlo
los requisitos minimos que se vana anecesitar para poder instalar GNS3 son:

- Procesador de 64 bits
- 4 GB de RAM (Se recomienda 8 GB o mas)
- Conexion a internet
- VirtualBox o VMware (Opcional)
- 1 GB de espacio en el disco
- Habilitar la virtualizacion (VT-x/AMD-V) en la BIOS

## Sistemas Operativos compatibles

- Windows
- Linux
- MacOS

## Pasos de Instlacion 
los pasos para poder tener GNS3 en nuestro dispositivos son:

1. Verificar que el equipo cumpla con los requisitos mínimos.
2. Ingresar a la página oficial de GNS3.
3. Descargar la versión correspondiente al sistema operativo.
4. Ejecutar el instalador.
5. Aceptar los permisos y seleccionar los componentes a instalar.
6. Finalizar la instalación.
7. Abrir GNS3 y completar la configuración inicial.


## Cofiguracion Inicial
para hacer la configuracion inicial al entrar a GNS3 tnemos que:

- Seleccionar el servidor local (Local GNS3 Server)
- Configurar VirtualBox o VMware (si se utilizarán máquinas virtuales).
- Verificar que el servidor local esté funcionando correctamente.
- Importar las imágenes IOS o de otros dispositivos que se utilizarán.
- Crear un proyecto de prueba para comprobar que la instalación fue exitosa.

## Verificación de la instalación

Para comprobar que GNS3 se instaló correctamente, crear un proyecto nuevo, agregar un dispositivo (por ejemplo, un router) e iniciar la simulación. Si el dispositivo se ejecuta sin errores, la instalación fue realizada con éxito.
